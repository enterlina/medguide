# Nebius × NVIDIA Hackathon — Submission Checklist

**Status:** Planning checklist; verify current eligibility, deadlines and rules at the [official Devpost rules page](https://nebiusglobalaihackathon.devpost.com/rules) before submitting.

## Team and eligibility
- [ ] Confirm both collaborators are registered/eligible participants.
- [ ] Confirm team membership in the hackathon platform.
- [ ] Confirm project category and deadline/timezone.

## Build
- [ ] Clearly document prior MedGuide work versus hackathon-created code.
- [ ] Integrate an eligible NVIDIA open-source model.
- [ ] Demonstrate real model inference running via permitted Nebius infrastructure.
- [ ] Implement and test one end-to-end medication analysis workflow.
- [ ] Provide citations, uncertainty handling and medical disclaimer.
- [ ] Run evaluation with synthetic representative examples.

## Open source and reproducibility
- [ ] Publish the required source code.
- [ ] Verify MIT license and third-party licenses are appropriate.
- [ ] Include real setup/run instructions after implementation.
- [ ] Provide sample environment variable names without secrets.
- [ ] Document model name/version and where it is hosted.
- [ ] Confirm no patient-identifying data or API keys are committed.

## Presentation and submission
- [ ] Deploy working demo or provide permitted testable build.
- [ ] Make short English walkthrough video and verify video rules.
- [ ] Add Figma link (optional design documentation).
- [ ] Add demo video, working link and project description to README.
- [ ] Complete all Devpost submission fields.
- [ ] Submit before official deadline; verify submission confirmation.

## Known limitations
This is a research prototype, not clinically validated medical software. Lack of identified interaction is not proof of safety.
